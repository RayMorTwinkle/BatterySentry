## 下载与安装

下载 `BatterySentry-v1.1.0-macos-arm64.zip`（Apple Silicon，macOS 13+），解压后把 `BatterySentry.app` 拖进「应用程序」。此版本使用 ad-hoc 签名，未公证；若 macOS 阻止首次打开，可运行：

```bash
xattr -dr com.apple.quarantine /Applications/BatterySentry.app
open /Applications/BatterySentry.app
```

## 更新内容

- 新增跨全屏空间的强提醒浮窗，默认开启；同时保留声音、语音和系统通知。
- 严重低电量时重复提醒。阈值可设为 5%–30%，间隔可设为 1–30 分钟，默认 10%／5 分钟；支持确认本轮和暂停 30 分钟。
- 新增「30 秒后测试」、提醒时间日志和专注模式设置提示，便于在游戏中验证。
- 支持带 Time Sensitive 能力的开发者签名；系统许可不足时自动回退为 Active 通知。

## 通知级别说明

本次下载包使用 ad-hoc 签名，系统通知实际为 Active。Time Sensitive 需要有效的 Apple 签名身份及系统许可；全屏浮窗、提示音和语音在本包中仍可用。建议在「系统设置 → 专注模式 → 游戏」允许电量哨兵通知。
